# 🔗 TCP vs UDP (Transport Layer Protocols)

TCP and UDP are protocols used in the Transport Layer of the TCP/IP model.

They define how data is sent between devices.

---

## 📦 What is TCP?

TCP (Transmission Control Protocol) is a reliable, connection-based protocol.

### Features:
- Connection-oriented
- Ensures data delivery
- Error checking
- Data arrives in order

### Used in:
- HTTP / HTTPS (web browsing)
- FTP (file transfer)
- Email services

---

## ⚡ What is UDP?

UDP (User Datagram Protocol) is a fast, connectionless protocol.

### Features:
- No connection required
- Faster than TCP
- No guarantee of delivery
- No order checking

### Used in:
- Video streaming
- Online gaming
- DNS queries

---

## 📊 Key Differences

| TCP | UDP |
|-----|-----|
| Reliable | Fast |
| Connection-based | Connectionless |
| Error checking | No error checking |
| Slower | Faster |

---

## 📌 Example

Opening a website → TCP (needs accuracy)  
Streaming video → UDP (needs speed)

---

## 🛡 Why SOC Analysts Must Know This

- Helps analyze network logs
- Identify attack types
- Detect unusual traffic
- Understand protocol behavior

---

## ✅ Summary

TCP = Reliable but slower  
UDP = Fast but unreliable
