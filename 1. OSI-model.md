# 🌐 OSI Model (Open Systems Interconnection)

The OSI Model is a 7-layer framework that explains how data travels across a network.

SOC analysts use it to understand where attacks happen.

---

## 📊 The 7 OSI Layers (Top to Bottom)

| Layer | Name | Purpose |
|------|------|--------|
| 7 | Application | User interaction (HTTP, FTP) |
| 6 | Presentation | Data formatting & encryption |
| 5 | Session | Manages connections |
| 4 | Transport | Data transfer (TCP, UDP) |
| 3 | Network | IP addressing & routing |
| 2 | Data Link | MAC address & frames |
| 1 | Physical | Cables & hardware |

---

## 🛡 Why OSI Model Matters for SOC?

- Helps trace attack location
- Understand network logs
- Identify attack types
- Improve troubleshooting

---

## 📌 Example

Phishing email → Layer 7  
DDoS attack → Layer 4  
IP spoofing → Layer 3  

---

## ✅ Summary

OSI Model breaks network communication into 7 layers, helping SOC analysts analyze security threats efficiently.
