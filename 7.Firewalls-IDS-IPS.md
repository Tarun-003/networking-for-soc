# 🛡 Firewalls, IDS & IPS (SOC Basics)

Firewalls, IDS, and IPS are security systems used to monitor and protect networks from attacks.

---

## 🔥 What is a Firewall?

A firewall is a security device that controls incoming and outgoing network traffic based on rules.

### 📌 Types of Firewalls

- Packet Filtering Firewall
- Stateful Firewall
- Next-Generation Firewall (NGFW)

### 🛡 Functions:
- Allow or block traffic
- Filter based on IP, port, protocol
- Prevent unauthorized access

---

## 🚨 What is IDS?

IDS (Intrusion Detection System) monitors network traffic and detects suspicious activity.

### 📌 Types:
- Network-based IDS (NIDS)
- Host-based IDS (HIDS)

### ⚠ Behavior:
- Detects attacks
- Generates alerts
- Does NOT block traffic

---

## 🚫 What is IPS?

IPS (Intrusion Prevention System) not only detects but also blocks malicious activity.

### 📌 Features:
- Detects threats
- Automatically blocks attacks
- Works in real-time

---

## 📊 IDS vs IPS

| Feature | IDS | IPS |
|--------|-----|-----|
| Detect attacks | Yes | Yes |
| Block attacks | No | Yes |
| Placement | Passive | Inline |
| Action | Alert only | Alert + Block |

---

## 🛡 Why These Matter in SOC?

- Monitor network traffic
- Detect intrusions
- Prevent attacks
- Generate alerts for investigation

---

## 🚨 Real SOC Example

- IDS alert → Suspicious traffic detected  
- IPS action → Blocks malicious IP  
- Firewall → Restricts access based on rules  

---

## ✅ Summary

Firewall controls traffic, IDS detects threats, and IPS detects + prevents attacks.
