# 📡 Network Monitoring Basics (SOC)

Network monitoring is the process of observing network traffic to detect suspicious activity and ensure security.

SOC analysts use monitoring tools to identify threats in real-time.

---

## 📌 What is Network Monitoring?

It involves:
- Capturing network traffic
- Analyzing data packets
- Detecting abnormal behavior

---

## 🧰 Tools Used

- SIEM (Splunk, ELK)
- Wireshark (packet analysis)
- IDS/IPS systems
- Network monitoring tools (Nagios, Zabbix)

---

## 🔍 What SOC Analysts Monitor

- Incoming and outgoing traffic
- IP addresses
- Ports and protocols
- Login attempts
- Data transfers

---

## 🚨 Signs of Suspicious Activity

- Multiple failed login attempts
- Unusual traffic spikes
- Unknown IP communication
- Access to malicious domains
- Large data transfers

---

## 📊 Logs Used in Monitoring

- Firewall logs
- Server logs
- Application logs
- DNS logs
- Authentication logs

---

## 📌 Example

Repeated SSH login attempts from same IP  
→ Possible brute force attack

---

## 🛡 Why Network Monitoring is Important

- Detect attacks early
- Prevent data breaches
- Identify malicious behavior
- Improve security response

---

## ✅ Summary

Network monitoring helps SOC teams continuously observe network activity and detect threats before they cause damage.
