# 🌍 IP Addressing for SOC Analysts

An IP address (Internet Protocol address) is a unique identifier assigned to every device on a network.

It allows devices to communicate with each other.

---

## 📌 Types of IP Addresses

### 🌐 1. Public IP

- Used on the internet
- Assigned by ISP
- Unique globally

Example:
8.8.8.8

---

### 🏠 2. Private IP

- Used inside local networks
- Not accessible from internet directly

Ranges:
- 10.0.0.0 – 10.255.255.255
- 172.16.0.0 – 172.31.255.255
- 192.168.0.0 – 192.168.255.255

Example:
192.168.1.10

---

## 🔢 IPv4 vs IPv6

### IPv4
- 32-bit address
- Example: 192.168.1.1

### IPv6
- 128-bit address
- Example: 2001:0db8:85a3::8a2e:0370:7334

---

## 🔁 Static vs Dynamic IP

| Type | Description |
|------|------------|
| Static IP | Fixed address |
| Dynamic IP | Changes automatically (DHCP) |

---

## 🌍 Loopback Address

- Used to test local machine
- IP: 127.0.0.1

---

## 🛡 Why IP Addressing is Important for SOC?

- Identify attacker source
- Track suspicious activity
- Analyze logs
- Block malicious IPs

---

## 🚨 Suspicious IP Examples

- Repeated login attempts from unknown IP
- Traffic from blacklisted IP
- Multiple requests from same IP (possible attack)

---

## 📌 Example

Multiple failed SSH logins from 185.x.x.x  
→ Possible brute force attack

---

## ✅ Summary

IP addresses uniquely identify devices and are essential for monitoring, detecting, and investigating cyber attacks.
