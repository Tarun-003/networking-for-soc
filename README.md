# 🌐 Networking Basics for SOC

Networking is the foundation of cybersecurity.  
SOC analysts must understand how systems communicate to detect attacks.

---

## 📌 What is Networking?

Networking is the process of connecting computers and devices to share data.

Example:
- Accessing websites
- Sending emails
- File sharing

---

## 🧱 Types of Networks

| Type | Description |
|------|------------|
| LAN | Local Area Network (small area like home/office) |
| WAN | Wide Area Network (large area like internet) |
| MAN | Metropolitan Area Network (city-level network) |

---

## 🌍 What is an IP Address?

An IP address is a unique identifier for a device on a network.

Example:
- 192.168.1.1 (Private IP)
- 8.8.8.8 (Public IP)

---

## 🔗 Protocols (Rules of Communication)

Protocols define how data is transmitted.

Common protocols:
- HTTP / HTTPS → Web traffic
- DNS → Domain name resolution
- TCP → Reliable communication
- UDP → Fast communication

---

## 🚪 Common Ports

| Port | Service |
|------|--------|
| 22 | SSH |
| 80 | HTTP |
| 443 | HTTPS |
| 21 | FTP |
| 3389 | RDP |

---

## 📦 How Data Travels (Simple Flow)

1. User sends request
2. Data is broken into packets
3. Packets travel through network
4. Destination receives and reassembles data

---

## 🛡 Why Networking is Important for SOC?

- Understand attack entry points
- Analyze logs and traffic
- Detect suspicious behavior
- Identify attacker movement

---

## ✅ Summary

Networking helps SOC analysts understand how data moves, making it easier to detect and prevent cyber attacks.
