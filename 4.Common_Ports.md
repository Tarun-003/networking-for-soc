# 🚪 Common Ports for SOC Analysts

Ports are communication endpoints used by network services.

Each service runs on a specific port number.

---

## 📊 Important Ports to Remember

| Port | Protocol | Service | Description |
|------|----------|--------|-------------|
| 20/21 | TCP | FTP | File transfer |
| 22 | TCP | SSH | Secure remote login |
| 23 | TCP | Telnet | Unsecure remote login |
| 25 | TCP | SMTP | Email sending |
| 53 | UDP | DNS | Domain resolution |
| 67/68 | UDP | DHCP | IP assignment |
| 80 | TCP | HTTP | Web traffic (unsecured) |
| 110 | TCP | POP3 | Email retrieval |
| 143 | TCP | IMAP | Email access |
| 443 | TCP | HTTPS | Secure web traffic |
| 3389 | TCP | RDP | Remote desktop |

---

## 🛡 Why Ports Matter in SOC?

- Identify type of traffic
- Detect suspicious activity
- Understand attack targets
- Analyze logs effectively

---

## 🚨 Suspicious Port Activity Examples

- Port 3389 (RDP) from unknown IP → Possible attack
- Port 22 (SSH) brute force attempts
- Port 80/443 unusual traffic → Web attack

---

## 📌 Real Example

Multiple failed logins on port 22  
→ Possible SSH brute force attack

---

## ✅ Summary

Ports help identify services and are crucial for detecting attacks in SOC environments.
